---
title: dsh.fish REST API
description: Search the dsh.fish catalog, inspect artifacts and install plans, read reviews, and mirror the catalog with the public JSON API.
---

The public API is for discovery and read-only catalog integration. Start with the generated [OpenAPI document](/openapi.json); this page shows the shortest useful path.

## Search artifacts

```sh
curl -s 'https://dsh.fish/api/v1/artifacts?q=postgres&kind=mcp-server'
```

Use the returned stable `id` with the detail and install-plan endpoints:

```sh
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID'
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID/install-plan?profile=web'
```

An install plan is data, not a command to execute blindly. Display every file, package, and profile patch to the user. If a package needs a build allowance, require a separate confirmation.

## Read trust signals

```sh
curl -s 'https://dsh.fish/api/v1/artifacts/ARTIFACT_ID/reviews'
curl -s 'https://dsh.fish/api/v1/scoring'
```

The scoring endpoint returns the same model the [score guide](/docs/scoring) renders. Do not reproduce the formula as an independent constant in your own code.

## Mirror the catalog

Third-party directories and bots can keep a local copy of the whole catalog without crawling it. Poll the lightweight version endpoint and download a new snapshot only when `dataVersion` changes:

```sh
curl -s 'https://dsh.fish/api/v1/catalog/version'
curl -s 'https://dsh.fish/api/v1/catalog/snapshot' -o catalog.json
```

Store the snapshot with its version and `ETag`, and send `If-None-Match` on later downloads; an unchanged catalog costs a 304.

Public reads do not require an account; authenticated write operations use the scopes described in OpenAPI.
